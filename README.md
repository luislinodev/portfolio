## 🚀 Instalación

Clona el repositorio:

```bash
git clone https://github.com/luislinodev/portfolio.git

cd portfolio

npm install

npm run dev
```

## 📦 Build de producción

```bash
npm run build
```

Para probar el build:

```bash
npm run preview
```

## 🧪 Verificación

```bash
npm run astro check
```
